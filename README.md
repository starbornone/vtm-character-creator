# vtm-character-creator

The Vampire: The Masquerade Character Creator is a planned browser guide for making V5 standard clan neonates, from character concept to a rules-checked starting sheet. The project is in planning. See [the product plan](PLAN.md) for first-release scope and implementation milestones.
