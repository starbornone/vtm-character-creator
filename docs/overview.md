# Project overview

The Vampire: The Masquerade Character Creator is in development for players preparing a V5 vampire and Storytellers reviewing the starting build. The app currently renders a starter screen. The proposed first release is a browser guide for standard clan neonates using the Core Rulebook. [Product plan](../PLAN.md)

## Planned player workflow

1. Start with a character concept, Ambition, Desire, and clan. Record chronicle guidance as needed.
2. Assign Attributes and Skills, select Disciplines and powers, and choose an eligible Predator Type. The live ledger explains each allocation and grant.
3. Record Advantages, Flaws, Convictions, Touchstones, and relevant relationships. Apply starting XP and review the resulting sheet and any open Storyteller rulings.
4. Save a local draft, print the sheet, or send the Storyteller a brief with selected narrative details. Use a full JSON backup to move or restore the draft and a mechanical build link to share a preview.

## Release boundaries

The first release covers one vampire at a time and the seven named core clans. The supported workflow includes manual entries where the core rules can represent the choice. Those entries carry a Storyteller review flag. Additional character profiles, long-term advancement, coterie management, Foundry export, and a private Storyteller workspace are follow-up candidates. Browser-local storage and explicit sharing cover draft handling for the first release.
