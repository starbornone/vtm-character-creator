# Project overview

The Vampire: The Masquerade Character Creator helps players prepare a V5 vampire and Storytellers review the starting build. The guide connects narrative choices, the rules ledger, and a printable sheet for standard-clan neonates and newly Embraced fledglings. It includes the seven named core clans, ten Core Predator Types and their eligibility rules, and a starting set of Advantages and Flaws. Manual clan, Predator Type, Advantage, and Flaw entries carry their source or note into Storyteller review. [Product plan](../PLAN.md)

## Player workflow

1. Choose an age profile and enter a character concept, Ambition, and Desire. Record chronicle guidance as needed.
2. Choose a clan and its Disciplines and powers. For a neonate, choose an eligible Predator Type. Assign Attributes and Skills with any applicable Predator grant visible in the ledger.
3. Record Advantages, Flaws, Convictions, Touchstones, and relevant relationships. Apply starting XP if the age profile grants it and review the resulting sheet and any open Storyteller rulings.
4. Open **Review & Print** to resolve open choices and print the character sheet.

Name a browser draft at any step to autosave it. Each saved character resumes at its own last step. Download a full JSON backup to restore the draft elsewhere, share a read-only mechanical build link, or export a Markdown Storyteller brief with open rulings and selected narrative sections.

## Release boundaries

The first release covers one vampire at a time and the seven named core clans. The supported workflow includes manual entries where the core rules can represent the choice. Those entries carry a Storyteller review flag. The fledgling profile adds a path for newly Embraced characters who will develop their Predator Type during play. Standard-clan ancilla creation is next. Browser-local storage and explicit sharing cover draft handling for the first release.
