# Project overview

The Vampire: The Masquerade Character Creator helps players prepare a V5 vampire and Storytellers review the starting build. The guide connects narrative choices, the rules ledger, and a printable sheet for fledglings, neonates, and ancillae. It includes the seven named Core clans, Caitiff, Thin-blood, ten Core Predator Types and their eligibility rules, and a starting set of Advantages and Flaws. Manual clan, Predator Type, Advantage, and Flaw entries carry their source or note into Storyteller review. [Product plan](../PLAN.md)

## Player workflow

1. Choose an age profile and enter a character concept, Ambition, and Desire. Record chronicle guidance as needed.
2. Choose a clan or blood status. Named clans and Caitiff allocate their starting Disciplines and powers. Thin-blood fledglings choose matched Merits and Flaws, with extra choices for Alchemy, Discipline Affinity, or Clan Curse. For a neonate or ancilla, choose an eligible Predator Type. Assign Attributes and Skills with any applicable Predator grant visible in the ledger.
3. Record Advantages, Flaws, Convictions, Touchstones, and relevant relationships. Apply starting XP if the age profile grants it and review the resulting sheet and any open Storyteller rulings.
4. Open **Review & Print** to resolve open choices and print the character sheet.

Name a browser draft at any step to autosave it. Each saved character resumes at its own last step. Download a full JSON backup to restore the draft elsewhere, share a read-only mechanical build link, or export a Markdown Storyteller brief with open rulings and selected narrative sections.

## Release boundaries

The first release covers one vampire at a time and the seven named core clans. The supported workflow includes manual entries where the core rules can represent the choice. Those entries carry a Storyteller review flag. The fledgling profile gives newly Embraced characters room to develop a Predator Type during play. The ancilla profile adds a larger starting XP and dot budget. Caitiff can choose any two Core Disciplines, use their own XP rate, and start with Suspect. Thin-blood creation covers the Core fledgling path. The optional Player’s Guide pack adds a documented set of clan, Predator Type, and power choices. After completing creation, players can record earned XP and replay purchases in the advancement journal. Drafts stay in the browser until players export or share them.
